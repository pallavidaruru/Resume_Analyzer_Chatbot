# Resume Analyzer Chatbot 🤖

Resume Analyzer Chatbot is a web-based application that analyzes a resume PDF and provides useful information about the resume.

## Features

- 📄 Upload a Resume PDF
- 📝 Extract text from the resume
- 🛠️ Detect technical skills
- 📊 Generate a Resume Score
- 💡 Provide resume improvement suggestions
- 💬 Ask questions about the resume using the chatbot

## Technologies Used

- Python
- Streamlit
- PyPDF

## How to Run

1. Install Python.
2. Install the required libraries:

   pip install -r requirements.txt

3. Run the application:

   streamlit run app.py

## Project Structure

- `app.py` – Main application
- `requirements.txt` – Required Python libraries
- `.gitignore` – Files excluded from GitHub

## Objective

The objective of this project is to help users analyze their resumes quickly and understand their skills, resume score, and areas for improvement.
